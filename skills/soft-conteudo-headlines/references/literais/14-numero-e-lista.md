# Literais: Número e lista (18 frases)

Frases como vieram do mercado, com a lacuna entre colchetes (e `X` onde entra o número). Cada bloco é um padrão: o esqueleto vale pra todas as frases dele. O dono escolhe, você preenche como manda o índice (`00-indice.md`) e a peça passa no gate de copy. A linha "Risco no gate" diz o que o gate reprova nesse quadro e como consertar.


## Só encaixam em um tipo de peça


### LST-PERGUNTAS-ANTES (9) · tipo de peça: lista

Esqueleto: [N] perguntas (ou uma pergunta-chave) pra fazer antes de [decisão] ou pra resolver [situação]

Risco no gate: item de sumário: a frase só rotula o tema, como item de índice: ponha o ganho ou o primeiro item dentro dela

- HL10 "X perguntas que você deveria se fazer antes de [ação]"
- HL20 "X perguntas para descobrir se [decisão/opção] vale a pena"
- HL32 "X perguntas que todo cliente faz antes de comprar [produto/serviço]"
- HL42 "X perguntas para fazer ao [especialista/mentor] antes de contratar"
- HL297 "O processo de [número] perguntas que uso antes de qualquer [decisão importante]"
- HL457 "Uma pergunta que muda completamente como você aborda [situação]"
- HL468 "Uma pergunta para fazer antes de qualquer [decisão] em [área]"
- HL474 "Uma sequência de [número] perguntas que resolve a maioria dos problemas em [área]"
- HL492 "Uma pergunta que faço ao final de cada [ciclo] para aprender mais rápido em [área]"
