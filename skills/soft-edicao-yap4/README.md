# Instalação e uso

Leia SKILL.md, references/PROCESSO.md, references/FERRAMENTAS.md e VALIDACAO.md. Python 3 e ffmpeg/ffprobe são pré-requisitos. Se houver requirements.txt, use ambiente virtual e `python3 -m pip install -r requirements.txt`. Não instalar durante render. Prepare modelo ASR, configure marca e fonte licenciada, preencha modelos e rode validação estrutural antes da montagem. Exemplos derivados de material real têm identificadores pessoais substituídos por MARCA no pacote; não servem como transcrição literal de auditoria. Mídia original não é distribuída. Nenhum upload ou publicação está implementado implicitamente.

O estado documental está pronto para revisão; a validação audiovisual integral permanece pendente. YAP4 inclui utilitários e processo; compositor histórico privado não é apresentado como engine portátil pronta. Palestra inclui pipeline histórico e assets, com limites documentados. Consulte VALIDACAO antes de usar.
