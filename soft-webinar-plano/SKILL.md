# Plano do webinar, o doc-mãe antes do roteiro

Webinar que converte não é roteiro bem escrito. É **plano com âncora afiada e oferta desenhada como STACK rica.** Produz o ANTES do roteiro: decide se é hora de webinar, escolhe o modo, crava a promessa, nomeia o mecanismo, desenha a oferta como pilha de itens desejáveis e fecha com os INSUMOS ORGANIZADOS.

> **plano = Plano de Posicionamento (INTEIRO, inline, na voz do dono) + Camada Webinar.** ~70% do que o roteiro consome já está lá: herda sem refazer, nunca aponta "veja lá".

**As 6 leis** (`shared-references/operacao-padrao.md` Seção 0), as duas duras: (5) **marca `[A CONFIRMAR]`, JAMAIS inventa**; (6) **TABELAS e LISTAS, nunca paredão de prosa**. **Processo:** Passos na ordem, **para nos STOP**, **gate por dentro** antes de mostrar. **Modo A:** monta do zero. **Modo B:** "não converte / quero refinar" → Passo A. Detecta na 1ª mensagem.

## Output Contract
**Um doc só, o Plano de Webinar**, montado DEPOIS do intake, **DENSO: tabelas e listas, nunca prosa corrida** (Lei 6; o paredão de prosa foi o anti-padrão que a auditoria reprovou). Ordem: **Como usar** → **0 HERANÇA** → **3 decisões-mãe** → **1 OFERTA como STACK** → **2 PROMESSA + BIG DOMINO + NÍVEL** → **2b ABERTURA** → **3 DIAGNÓSTICO + MECANISMO** (o ensino, maior bloco) → **4 PERSONA** → **5 PROVAS + PROVA EXTERNA** → **6 CONTA** → **7 FORMATO** → **8 PITCH** → **9 INSUMOS ORGANIZADOS** (FINAL) → **`[A CONFIRMAR]`**. Forma de saída de cada seção: `montagem-secoes-0-9.md`. Gate **por dentro**; sai só o doc limpo.

## Passo 0-1, absorve o posicionamento e decide se é hora de webinar (NÃO PULE)
**P0:** fonte na ordem **posicionamento colado → descrição do projeto → mensagens anteriores**. **Absorve o posicionamento inteiro** (a Herança é seção, não ponteiro) e puxa **3-5 falas de DOR + 3-5 de DESEJO** literais, com o N. Sem posicionamento, o furo vira `[A CONFIRMAR]` e `soft-posicionamento` crava antes; sem mecanismo nomeado, PUV e batismo ficam `[A CONFIRMAR]`. O que extrair, os estados de entrada e o arsenal pro especialista que duvida: `intake-consultivo.md` "Passo 0" + `arsenal-vantagens-webinar.md`.

**P1:** webinar é degrau 2 (Funil → Webinar → Lançamento): **não valida do zero, escala o validado.** Confirma os cinco na PRÁTICA: autoridade real · narrativa validada · promessa validada · UM case real percorreu o caminho · funil de entrada já vende previsível. **Faltou um → volta pro funil, encerra a conversa.** Ticket < ~3k não paga a estrutura (~R$5.000/rodada). Tom: consultor que **mede antes de opinar**. Custo, sinais de "ainda não" e a decisória: `escolha-carta-mt-webinario.md`. **STOP**, espera OK.

## O INTAKE CONSULTIVO (uma decisão por bloco, STOP em cada)
Régua: **deriva do posicionamento e CONFIRMA o que existe; PERGUNTA só o que falta.** Furo = `[A CONFIRMAR]`. Teto: 3 perguntas abertas/rodada. Os 6 blocos, com **STOP em cada**: (1) **O QUE VENDER + ticket → canal** · (2) **PRA QUEM** (recorte, persona-âncora, nível, tráfego) · (3) **PROMESSA + BIG DOMINO + MECANISMO + sacada de graça** · (3b) **ABERTURA** (título, 5 ganchos, premise, USP falada S10, Mundo Ideal) · (3c) **NARRATIVA + MUNDOS + FASCINATIONS** · (4-6) **FORMATO · A CONTA · PROVAS**.

Regras duras: **UMA oferta** por webinar · **≤~R$3.000 checkout, >~R$3.000 fecha no 1:1** · meta ÷ ticket que não cabe **SOBE o ticket** · persona NÃO se inventa, crenças **rotuladas INTERNA x EXTERNA** (avatar Soft = **6º nível**) · promessa UMA, `DESEJO + MECANISMO − OBJEÇÃO` · Big Domino **nova oportunidade, NUNCA melhoria** · mecanismo é **SEQUÊNCIA** · **GATE ANTI-RÓTULO** · formato pelo **ESTÁGIO** (ao vivo valida → grava → perpetua) · nenhuma prova inventada (Lei 5). Pergunta literal de cada bloco, tabelas, benchmarks e cold start: `intake-consultivo.md`.

## A MONTAGEM (Herança inteira + STACK rica + diagnóstico/mecanismo reais)
Monta o doc DENSO: abre com a **Seção 0, a HERANÇA** (o posicionamento absorvido por completo, inline, na voz do dono, nunca resumo nem ponteiro: foi a falha que a auditoria reprovou), empilha as 8 seções, fecha com a **Seção 9, INSUMOS ORGANIZADOS** (peças soltas, não resumo). As leis que o gate cobra: **tripartição** MÓDULOS (pelo que a pessoa VIRA, sem preço) × CURSOS de prateleira (nome próprio + PREÇO real checável, NUNCA "bônus") × **BÔNUS** (a palavra reservada a UM item sem preço) · **STACK rica**, cada item matando UMA objeção · **bônus-âncora MAIOR que o produto** · **2 moedas separadas** (desconto pra todos x 15-primeiros pra quem corre) · **rede pro 16º** · **soma riscada** checável · Diagnóstico **de fora pra dentro** · Mecanismo como **SEQUÊNCIA real**, nunca "3 viradas" · **Faca Soft**. Cada seção por dentro, com o cardápio a-h, as camadas de escassez, o pitch em 10 passos e a ordem canônica de revelação: `montagem-secoes-0-9.md`.

## Passo A, AUDITORIA de webinar existente (Modo B)
"Meu webinar não converte / quero refinar": **NÃO reescreve do zero.** Audita, reescreve **só os blocos quebrados**. Pede vídeo/transcrição + métricas e cruza cada drop da retenção com o bloco no timestamp. Saída = o trio (bloco + sintoma + premissa) priorizado + os blocos reescritos. Mapa: `gate-e-anti-patterns.md` "Passo A" + `analise-webinario-existente.md`.

## O GATE (roda por dentro, silencioso, NÃO imprime)
Só doc com **VEREDITO=PASSA** vai pro usuário; **VEREDITO = o PIOR item, um ✗ refaz O ITEM**, não o doc. Os 25 checks (é hora de webinar · HERANÇA inline · STACK na tripartição · 15-primeiros + 2 moedas + rede + soma riscada · PUV + jornada · garantia + frame · estrutura REAL com **zero "3 viradas"** · Big Domino nos 3 momentos · UMA promessa · anti-rótulo · abertura completa · crenças rotuladas · nível de consciência · PROVA EXTERNA real · modo pelo estágio · a conta fecha · canal + CTA · pitch completo · Seção 9 · Leis 5 e 6 · Harry + C/U/B · naming honesto · nicho regulado · anti-IA HARD), com o critério de cada um e a tabela sintoma → correção: `gate-e-anti-patterns.md`. Anti-IA: **no chat, CTRL+F do em-dash e da família "travar"**; no Code, `python3 scripts/lint_copy.py`.

## When NOT to use
Posicionamento / nomear o método / PUV de marca → **soft-posicionamento**. Aula / roteiro / slides / deck → **soft-webinar-script**. Páginas → **soft-webinar-paginas**. E-mails / WhatsApp / anúncios / pós → **soft-webinar-mensagens**. Micro-aula / carta / VSL / landing / isca → **soft-funil**. Fechamento 1:1 / objeção → **soft-vendas**. "Por onde começo" → **soft-leon**.

## Handoff
O Plano aprovado entra no **soft-webinar-script** (o roteiro nasce de trás pra frente): S2b+S0+S3a+S4 = Atenção e Diagnóstico; S2+S3b+Mundo Ideal = Mecanismo; S1+S8 = Ação; S9 = o que páginas/ads consomem. O script lê só este doc. Fechamento 3k+ = **soft-vendas**.
